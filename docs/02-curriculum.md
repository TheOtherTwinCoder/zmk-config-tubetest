# PhysicsQuest Curriculum — 10 Levels, Age 5 → Grade 12

**Conventions**
- **BQ** = Big Question (chapter-level inquiry hook).
- **Project** = student-built artifact at end of chapter.
- **Source tags**: `NGSS`, `UK-NC`, `NCERT`, `IB`, `SG-MOE`, `OpenStax-CP`, `PhET`, `AAAS-2061` (misconception source), `FCI`, `ISLE`, `Driver-1994`.
- Every lesson follows ISLE: Observe → Pattern → Explanation → Test → Apply.
- Each level ends with a **Boss Challenge** integrating prior chapters and a validated **Concept Inventory** pre/post.

## Cross-cutting strands (present at every level)

| Strand | Description |
|---|---|
| **Scientific habits** | Predict-before-test, document observations, sketch models, give reasons. |
| **Math ladder** | Counting → measuring → ratios → algebra → trig → calculus, introduced only when required by physics content. |
| **Mistake museum** | Famous wrong theories per level (Aristotelian motion, phlogiston, luminiferous aether) used to teach falsifiability. |
| **Women & global physicists** | Marie Curie, C. V. Raman, Chien-Shiung Wu, Lise Meitner, Vera Rubin, etc., woven into chapter intros. |
| **Real-world translation** | Every level ends with a "design a solution to a real problem in your neighborhood" task. |
